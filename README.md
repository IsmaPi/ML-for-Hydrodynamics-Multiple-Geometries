# Applying Machine Learning to Hydrodynamics for the Generalization of Multiple Geometries

Bachelor thesis by **Ismael Picazo Flores**, supervised by **Prof. R. P. Peláez** (Universidad Autónoma de Madrid / IE University).

## Overview

This project learns the hydrodynamic mobility operator for Stokes flow using an E(3)-equivariant TensorNet architecture. Given particle positions and applied forces, the model predicts per-particle displacements that would result from the full many-body hydrodynamic interactions.

The model is trained on ground-truth data generated by [libMobility](https://github.com/stochasticHydroTools/libMobility) for two boundary geometries (open and triply periodic) and achieves ~4.9% relative error on held-out test configurations.

## Architecture

The model is built on [TensorNet](https://arxiv.org/abs/2306.06482) from the [TorchMD-NET](https://github.com/torchmd/torchmd-net) framework, with modifications for the hydrodynamic problem:

- **Force injection**: Per-particle forces are converted to skew-symmetric tensors and added to the antisymmetric (A) channel of the tensor features after the embedding layer, preserving O(3) equivariance.
- **Geometry conditioning**: A learned embedding maps the geometry type (open or periodic) to a vector added to node features, letting the model specialize per geometry.
- **Per-edge output head**: An MLP with RBF distance features predicts two scalar mobility coefficients (alpha, beta) per particle pair. Displacements are computed as a scatter sum of isotropic and anisotropic contributions, mirroring the structure of the RPY mobility tensor.

See the thesis (Section 2.3.2) for full details.

## Results

Trained on 330,000 samples (clouds + pairs) across both geometries, N ∈ {16, 32, 64}.

| Metric | Value |
|--------|-------|
| Test relative error | 4.9% |
| Test MSE | 5.7 × 10⁻⁵ |
| Test MAE | 4.0 × 10⁻³ |
| NBody (open) rel. error | ~0.5–3% |
| PSE (periodic) rel. error | ~9% |
| Parameters | ~1.03M |
| Training time | ~2 hours (RTX 4080 SUPER) |
